# 方法说明

本文档说明到访风险分析与票额安排的口径、证据等级与已知边界。
数据为本地合成资料；所有结论可由 `python -m venueflow.cli validate`
与 `python -m pytest` 复算。

## 1. 记录口径

- **版本**：同 `booking_id` 的多 `revision` 是完整替代，人数不相加；
  截点重建只取该截点已提交的最高 revision（`io.resolve_bookings`）。
- **成熟性**：未闭场场次的 `actual_count` 缺失不补 0，也不进入拟合；
  截点 `as_of` 下只有接待日早于 `as_of` 日期的场次算成熟。
- **取消**：`cancelled_count` 为累计值。资料不含取消发生时刻，
  因此截点验证一律使用 gross 模式（只依赖原始预约数），不把截点后
  才发生的取消当作已知；运营预测使用 net 模式（当前取消确已知），
  且当前净预约是未来净预约的上界——超员风险估计为保守方向。

## 2. 到访风险模型选型比较

候选方案与实测结论（840 条成熟预约、140 个成熟场次）：

| 方案 | 实测问题 | 结论 |
| --- | --- | --- |
| 逐人独立伯努利（按历史平均到访率） | 团体出席方差被严重高估：8 人商业团缺席人数经验上仅取 {1,2,3}，方差 ≈0.8，远低于二项 ≈1.4；且"平均到访率"掩盖规模效应（小团出席率 0.5，大团 0.83+） | 拒绝：同一团体的成员不是相互独立的硬币 |
| 逐预约独立卷积（按规模的减员分布） | 场次总到访残差 sd≈1.1，而独立卷积隐含 ≈2.6：同场预约间存在负相关，独立假设使区间过宽（时间外 50% 区间覆盖率 100%，明显过保守） | 仅作陌生构成的保守退路 |
| **场次总量模型：Σ(类型,规模) 单元均值 + 场次残差**（采用） | 时间外覆盖率 50%/80%/95% = 0.38/0.88/0.88，在二项抽样噪声内通过校准门槛 | 采用 |

采用模型的要点：

- 公益团体：`actual_count` 在全部 210 条成熟记录中恒等于净预约，
  按净额确定到场建模（`deterministic_net`）。
- 商业团体：按 (类型, 净规模) 分级估计出席均值；单元成熟证据不足
  15 条时降级为合并证据均值，并在输出中标注。
- 场次残差：经验分布（本资料支撑集 {-2..+2}），与各场馆无关。
- 同团体跨预约相关：ICC 估计 ≈ -0.07，未检出，故不加团体层随机
  效应；该检验每次 `validate` 重算，证据变化时结论可推翻。
- 未来售出（情景评估）：按历史商业团体规模池抽团、逐团抽出席，
  固定种子蒙特卡洛（20000 次）并入；新到团体按独立噪声处理，
  这是明确的假设而非数据结论。

## 3. 时间外验证与提前期质量

`validate` 对每个观察截点只用截点前成熟的证据拟合，预测截点后
闭场的场次（gross 模式，无取消时点泄漏），输出：

- 校准门槛：各名义覆盖率与实测覆盖率的偏差在二项检验容差
  （z=2.5）内，未通过则整场结论只能使用界限；
- 分提前期（0-7 / 7-30 / 30-90 天）的 MAE、bias 与覆盖率；
- 分场馆的覆盖率与出席率。

当前结果：三个提前期桶 MAE 均 ≈1.0 人，bias 接近 0，覆盖率达标；
提前期对本资料的预测质量影响不显著（取消率与出席率对提前期稳定）。

## 4. 证据迁移性

`validate` 输出迁移性检验，结论（本资料）：

- **场馆间**：A/B/C 出席率 0.773/0.775/0.775，最大差 0.002，
  中心模型可跨馆迁移；但每个场馆仍要求 ≥10 个成熟场次，否则降级。
- **时段/星期**：星期间出席率最大差 0.017，无实质时段效应。
- **政策改变**：场馆 A 于 2026-04-01 由 POL-old（取消时限 24h）切换
  POL-new（48h）。切换前后取消率 0.135 vs 0.134、出席率 0.772 vs
  0.775，差异在噪声内——这是"检验后未发现差异"，不是"假设无差异"；
  后续数据若出现差异，该检验会报警。场馆 B/C 无任何政策记录，
  其政策参数无从推断，状态查询中明示。
- **容量附近行为**：历史净预约强度最高 0.85、实际满载率最高 0.73，
  没有任何场次接近容量。计划净预约强度超过 0.85 时，结论自动降级
  为 extrapolated：概率仅供参考，决策必须同时看 Markov/Cantelli
  界限。
- **新开场馆**：无成熟证据时等级为 unsupported，只输出无分布界限，
  不把其他场馆的历史说成该馆的确定风险。

## 5. 分布之外的界限

每场风险输出同时给出：

- Markov 界限 P(T≥c) ≤ E[T]/c；
- Cantelli（单侧切比雪夫）界限；
- 硬上界：当前净预约总和（取消只减不增，出席不超过净额）。

证据等级不足时，这些界限是唯一可用的结论形式。

## 6. 票额安排约束语义

- `base_limit(t)`：公开截止前 = 容量 − protected_capacity（公益名额
  不参与商业超放）；截止后只释放尚未确认部分 = 容量 − protected +
  max(0, protected − 公益已确认净额)。
- 商业限额 ≤ base_limit 为常规销售；超过即为**超放**，仅当
  满售假设下 P(到访>容量) ≤ alpha 且期望补偿 ≤ 预算时才允许确认。
- 商业限额不得低于已售商业净额：已确认预约（含公益）是承诺，
  预测变化不产生无声撤回；风险升高只能形成新的销售边界（停售/
  调额建议），由 `boundary` 命令记录并附分析依据。
- 公益预约只占用 protected_capacity 内尚未确认部分，与商业池隔离。
- 补偿暴露 = E[max(0, 到访−容量)] × 每人补偿，对照预算报告余量。
- 资料无价格字段，收入以商业净售名额为代理并明示。

## 7. 需求删失

sales_controls 的售停区间是主动限制，不是需求为 0。状态查询对每场
给出分类：限制停售（附区间内被拒询价的人数与团数）/ 正常销售 /
未售 / 无人需求。分析侧的需求证据只使用 enquiries 的到达与被拒
记录，不使用售停区间内的销量。

## 8. 候补与接受

- 候补按 `submitted_at` 次序办理；整团接纳，不拆团到零散名额；
  同一提交时刻（同优先级）内允许比较可行组合，取接纳团体数最多者；
  不得跳过可完整接受的更早团体（`verify` 逐笔复核）。
- 每次办理使用当时的真实剩余额度（生效限额 − 实时商业净售），
  不使用任何历史建议值；被搁置的候补在下次办理时重新参与。
- 任何已接受的新预约立即进入承诺与风险预测。

## 9. 台账与审计

原始资料（data/）不可变；运营动作只追加到 var/ledger.jsonl：
decision（含分析依据）、boundary（销售边界及依据）、acceptance、
waitlist_disposition。`verify` 重放台账，复核：校准门槛、每笔决定
确认时的约束、每笔接受不超当时剩余、公益保留不被商业占用、承诺
无撤销语义、候补无跳过、边界必有依据。任何一项失败则整体失败。
